# Algoritmi pentru ONI si alte concursuri de informatica din Romania

Un pachet cu diversi algoritmi si template-uri pe care le folosesc la concursurile de informatica.
Pretty much doar Robert o sa vada asta, si eventual cine mai merge cu mine la AGM anul viitor.

## De adaugat

**Grafuri**
- [ ] Flux, flux maxim de cost minim
- [ ] Cuplaj maximal pe graf bipartit

**Structuri de date**
- [ ] Trucuri cu DSU
- [ ] Small to large pe arbore
- [ ] Binary descent pe arbore de intervale

**Siruri**
- [ ] KMP
- [ ] Suffix array
- [ ] Hashing

**Programare dinamica**
- [ ] Optimizarea DP-ului pe arbore
- [ ] Inegalitatile de la optimizarile de DP

**Matematica**
- [ ] XOR basis (daca pica asa ceva, oricum sunt generationally cooked)

## De consolidat

- **KMP** — nu prea l-am mai bagat, si am mereu norocul sa pice fix algoritmii despre care credeam ca nu pica.
- **Centroid** — vreau sa-l pot baga repede. Inca mi-e putin neclar cum face sa numere un drum o singura data, si vreau o implementare mai rapida si mai compacta.
- **Arbore virtual** — l-am invatat acum 15 minute, so don't expect much.
- **Algoritmul lui Mo**
- **Probabilitati, expected values**
- **Hashing** — ce pot face exact cu hash-urile si cum abordezi problemele cu ele.
- **SCC, BCC, 2CC** - o mica discutie cred ca ar fi foarte benefica, ca sa vad daca am inteles exact despre ce e vorba.
